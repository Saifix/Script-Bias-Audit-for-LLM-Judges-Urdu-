# Generated conditions

`opus-5.5-high.json` holds the two generated script conditions used in the experiments:

- `roman_translit`: Roman Urdu word-by-word transliterations of all 4 answer options for the 300 sampled items.
- `code_mixed`: Urdu–English code-mixed versions (Urdu matrix language, selected nouns in English) for all 300 items.

They were generated by **Claude Opus 5.5 (Anthropic) at high reasoning effort**. They were checked automatically (4
non-empty options per item, no Urdu script left, no word-count drift) and imported without human review.

Source text: Belebele (`facebook/belebele`, Urdu-script answer options), licensed CC BY-SA 4.0. This derived file is
shared under the same licence.

Load into the database (keeps existing rows unless `--replace`):

    python -m scripts.import_generated generated/opus-5.5-high.json \
        --model "anthropic/claude-opus-5.5 (high effort)" \
        --approve-as "auto-approved: Claude Opus 5.5 (high effort)"
